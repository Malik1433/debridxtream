## NAVIGATION BUTTON ANIMATIONS (CodePen glass style)

### Button States
```
default: 250ms ease-out [glass gradient #40FFFFFF→#10FFFFFF, border: #66FFFFFF, shadow: 0 18dp 26dp rgba(8,12,20,0.35)]
focus:   300ms ease-out [translateY: -6dp, scale: 1.05, glow: rgba(94,249,215,0.6) blur 18dp, highlight sweep]
active:  200ms ease-in  [translateY: -3dp, scale: 1.02, tint: #5EF9D7, text: #04181D]
rest:    200ms ease-out [translateY: 0, scale: 1.0, highlight alpha 0.3]
press:   120ms ease-in  [scale: 0.97, shadow depth 8dp]
```

### Transition & Effects
- Timing curve: cubic-bezier(0.37, 0, 0.63, 1).
- Focus triggers `buttonFloat` keyframe (translateY/scale/glow) over 300ms.
- Frosted light sweep `buttonSweep` runs 0→100% in 400ms ease-out on focus gain.
- Ripple: 280ms expanding circle, alpha 0.35→0, tinted #5EF9D7.

## EASING FUNCTIONS

- **ease-out**: cubic-bezier(0.4, 0, 0.2, 1) - Default for most
- **ease-in**: cubic-bezier(0.4, 0, 1, 1) - For exits
- **bounce**: cubic-bezier(0.34, 1.56, 0.64, 1) - For playful interactions
- **smooth**: cubic-bezier(0.25, 0.46, 0.45, 0.94) - For scrolling

═══════════════════════════════════════════════════════════════════════════════

## TIMING PRINCIPLES

- **Micro**: <150ms - instant feedback
- **Quick**: 150-250ms - button/icon interactions
- **Standard**: 250-400ms - card focus, page transitions
- **Slow**: 400-800ms - loading, major state changes
- **Ambient**: 1500-2000ms - subtle pulses, shimmers

═══════════════════════════════════════════════════════════════════════════════

## ANIMATION PHILOSOPHY

1. **Subtle & Professional** - No dramatic or distracting animations
2. **Purposeful** - Every animation has a clear purpose
3. **Consistent** - Same timing for similar interactions
4. **TV-Optimized** - Focus animations prominent for D-pad navigation
5. **Performance** - Use hardware-accelerated properties (transform, opacity)
6. **Accessibility** - Respect reduced motion preferences
