# Development Guide

## Prerequisites
- **Android Studio**: Iguana or later (Recommended).
- **JDK**: Java 11 or 17 (Target is Java 11).
- **Android SDK**: API 35 (Compile), API 26 (Min).

## Setup
1. Clone the repository.
2. Open in Android Studio.
3. Sync Gradle project.
4. Create a `local.properties` file if not present (Auto-generated by AS).

## Build Commands
Using the Gradle Wrapper (`gradlew`):

```bash
# Clean project
./gradlew clean

# Build Debug APK
./gradlew assembleDebug

# Build Release APK
./gradlew assembleRelease

# Run Unit Tests
./gradlew test

# Lint Check
./gradlew lint
```

## Running the App
- Connect an Android TV device or Emulator via ADB.
- Run `App` configuration in Android Studio.
- OR install via command line:
  ```bash
  ./gradlew installDebug
  ```

## Architecture
- **MVVM**: ViewModels store state (StateFlow).
- **DI**: Hilt (`@AndroidEntryPoint`, `@HiltViewModel`).
- **Coroutines**: Used for all async work.

## Key Libraries
- **Networking**: Retrofit + OkHttp.
- **Database**: Room.
- **Images**: Glide / Coil.
- **Player**: Media3 (ExoPlayer).
